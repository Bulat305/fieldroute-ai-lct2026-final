# ЛЦТ 2026 — чек-лист финальной сдачи

## Команда

`broCode`

## 1. Репозиторий

Рекомендуется использовать SourceCraft как основной конкурсный репозиторий.

После создания репозитория вставить сюда:

```text
SOURCECRAFT_URL = <добавить>
```

Резервный GitHub:

```text
https://github.com/Bulat305/fieldroute-ai
```

Перед сдачей проверить, что эксперты имеют доступ к репозиторию.

## 2. Документация

Основная документация находится в репозитории:

```text
README.md
docs/ARCHITECTURE.md
docs/ALGORITHM.md
docs/DATASET_AND_ASSUMPTIONS.md
docs/DEMO_SCRIPT.md
```

Для поля «Документация» можно использовать прямую ссылку на README или опубликованную документацию SourceCraft.

## 3. Прототип

```text
https://fieldroute-ai.onrender.com
```

Перед отправкой:

- открыть ссылку в режиме инкогнито;
- открыть с другого устройства;
- проверить `/health`;
- запустить Восток;
- выполнить оптимизацию;
- открыть `Объяснить выбор`;
- открыть отдельный маршрут бригады;
- выполнить срочное перепланирование;
- пройти Demo Mode.

## 4. Презентация

Пока добавить ссылку после подготовки финального PDF:

```text
PRESENTATION_URL = <добавить>
```

## 5. Дополнительные материалы

Рекомендуется приложить:

- резервную видеозапись демонстрации;
- архитектурную схему;
- при необходимости PDF с описанием алгоритма.

## 6. Что не загружать в публичный репозиторий

- `.venv/`;
- `__pycache__/`;
- `.env`;
- API keys;
- access tokens;
- приватные SSH-ключи;
- локальные credentials.

## 7. Финальная проверка перед отправкой

- [ ] SourceCraft содержит последнюю stable-версию.
- [ ] README открывается и понятен без устного объяснения.
- [ ] Render развернут из той же версии кода.
- [ ] Публичная ссылка работает без локального компьютера.
- [ ] Все встроенные регионы загружаются.
- [ ] Основной solver использует 10 секунд.
- [ ] Demo Mode проходит три шага.
- [ ] Презентация доступна по ссылке.
- [ ] Ссылки открываются без авторизации либо доступ экспертов настроен.
- [ ] Подготовлена резервная видеозапись.
